隱私權政策（Privacy Policy）

1. 存取哪些 Google 使用者資料

在使用者明確同意後，本程式使用 Gmail API 的 https://www.googleapis.com/auth/gmail.readonly 唯讀授權。此權限可讀取 Gmail 信件內文、標頭及附件；程式按指定的高鐵寄件者、關鍵字與信件特徵篩選與處理相關郵件。

我們不會用該權限寄送、修改或刪除 Gmail 郵件。Google 授權的權限範圍不會被技術性限制為只有高鐵寄件者，因此使用者應了解授權本身的存取範圍。

2. 資料使用目的

從高鐵相關郵件整理訂票、付款、改票、取消與預定搭乘資訊；取得電子車票證明附件；使用已知車票日期密碼開啟 PDF；驗證與本機歸檔，產生行程、待處理與歸檔報表。

3. 資料儲存與分享

本程式在使用者 Windows 電腦上儲存必要的行程資料（SQLite）、處理狀態、日誌，以及加密和無密碼的 PDF 副本。OAuth 授權憑證保存在使用者可管理的本機位置。程式不會主動把 Gmail 郵件資料傳送給 AI 模型或本程式開發者控制的伺服器，也不出售 Gmail 資料。

本程式需要向 Google 的 Gmail API 發送授權請求以讀取郵件。若使用者自行選擇將本機資料夾同步到 SynologyDrive、雲端備份或其他服務，相關同步與備份行為取決於使用者的設定及該服務的條款。

4. 資料保留、刪除與存取控制

資料由使用者在自己的電腦上管理；使用者可刪除歸檔 PDF、SQLite 資料庫及相關報表。對 Gmail 的存取可在 Google 帳戶安全性設定撤銷授權。本機或同步備份中的檔案可能需要使用者另外刪除。

5. 安全性與限制

程式使用最小必要的 Gmail 唯讀 OAuth 權限，但無密碼 PDF 仍可能包含個人行程或票務資料。建議使用 Windows 檔案權限、裝置加密及適當的備份安全措施。此程式尚非台灣高鐵或 Google 官方產品，且仍可能有格式解析不完整的情況。

6. Google API Services User Data Policy

本程式使用自 Google API 取得的資料，僅用於上述使用者明確授權的功能，不會將資料用於廣告、出售或其他無關目的。若功能或資料處理方式有重大改變，本政策將先行更新。

7. 連絡方式

如對本程式的 Gmail 授權或資料處理有疑問，請聯絡：trashmail0712@gmail.com
